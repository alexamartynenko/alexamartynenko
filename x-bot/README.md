# X-агент в Telegram для @jexor_studio

Бот в Telegram, через который ведется X: идеи, посты, ответы под чужими твитами, публикация.
Ничего не уходит в X, пока ты не нажмешь кнопку.

## Что он делает

| Ты делаешь | Бот отвечает |
|---|---|
| Пишешь идею (можно по-русски, можно надиктовать через клавиатуру) | Готовый пост на английском: хук, открытая петля, CTA. Кнопки: 🚀 сейчас, 🕒 в очередь, ✏️ править, 📝 черновик в Typefully, 🗑 |
| Жмешь ✏️ и пишешь, что поменять | Переписанный пост с теми же кнопками |
| Кидаешь ссылку на чужой твит (или `/reply текст`) | 3 варианта ответа, ты копируешь и постишь сама |
| `/ideas` | Ищет в сети свежие темы по твоим нишам и пишет посты под них |
| Ничего (каждый день в 09:00) | Сам присылает идеи дня и список инфлюенсеров, под кем ответить |

Публикация идет через Typefully API в аккаунт @jexor_studio (social set 350599).

Чего бот специально **не** делает: автолайки, автоподписки, автоответы. Это нарушает правила X,
а твой аккаунт сейчас чувствительный (галочка пропала, идет отток), риск бана слишком большой.
Ответы под чужими постами бот пишет, а постишь их ты руками — это 2 секунды и ноль риска.

## Ключи, которые нужно создать (сама, в чат их не присылай)

1. **Telegram-бот.** В Telegram открой @BotFather → `/newbot` → придумай имя → он выдаст токен.
   Это `TELEGRAM_BOT_TOKEN`.
2. **Claude API.** https://console.anthropic.com → Settings → API Keys → Create Key.
   Это `ANTHROPIC_API_KEY`. В Billing пополни на $10 и поставь месячный лимит (например $20),
   чтобы расход никогда не вышел за рамки.
3. **Typefully API.** Typefully → Settings → API → создай ключ с правом публикации.
   Это `TYPEFULLY_API_KEY`.

## Запуск (≈15 минут, на Railway)

1. Зайди на https://railway.com, войди через GitHub.
2. New Project → Deploy from GitHub repo → выбери этот репозиторий.
   В настройках сервиса укажи Root Directory: `x-bot`.
3. Вкладка **Variables** → добавь переменные из `.env.example` со своими ключами.
   Ключи живут только там, в репозиторий они не попадают.
4. Вкладка **Volumes** → Add Volume → путь `/data` (там бот хранит черновики между перезапусками).
5. Напиши своему боту `/start`. Он ответит твоим Telegram ID. Впиши его в `TELEGRAM_OWNER_ID`,
   Railway сам перезапустит бота. Теперь бот слушается только тебя.

Настройки по желанию: `TIMEZONE` (по умолчанию Europe/Moscow), `DAILY_TIME` (09:00),
`TOPICS` (темы для поиска), список инфлюенсеров — файл `influencers.txt`.

## Сколько это стоит в месяц

| Что | Цена |
|---|---|
| Railway (хостинг бота) | ≈ $5 |
| Claude API: ~10 постов и ~15 ответов в день + ежедневный поиск идей | ≈ $10–20 на Claude Opus 5.5; ≈ $5–10 если поставить `CLAUDE_MODEL=claude-sonnet-5-5` |
| Typefully | твой текущий план (API должен быть доступен на нем) |
| Telegram | бесплатно |

Итого примерно **$15–25 в месяц**. Для сравнения: Tweet Hunter $29–49, Hypefury от $29.
